# 🧠 Brain Tumor Classification

## 📌 Overview
Brain Tumor Classification is a deep learning-based project that classifies brain MRI images into tumor and non-tumor categories. It utilizes Convolutional Neural Networks (CNNs) to accurately identify tumors from medical images, aiding in early diagnosis.

## 🚀 Features
- **Automated Classification:** Detects and classifies brain tumors from MRI scans.
- **Deep Learning Model:** Uses CNN-based architecture for high accuracy.
- **Visualization:** Displays MRI images with classification results.
- **User-Friendly Interface:** Simple execution for medical professionals.
- **Performance Metrics:** Provides accuracy, precision, recall, and confusion matrix analysis.

## 🛠️ Tech Stack
- **Deep Learning:** TensorFlow, Keras
- **Image Processing:** OpenCV, NumPy, PIL
- **Data Handling:** Pandas, Scikit-learn
- **Visualization:** Matplotlib, Seaborn
- **Backend:** Python

## 🔧 Installation & Setup
### Prerequisites
- Python (>= 3.8)
- Git
- Jupyter Notebook
- Virtual Environment (optional but recommended)

### Steps
1. **Clone the Repository**
   ```sh
   git clone https://github.com/rakshashetty66/BRAIN-TUMOR-SVM.git
   cd BRAIN-TUMOR-SVM
   ```
2. **Create Virtual Environment (Optional but Recommended)**
   ```sh
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```
3. **Install Dependencies**
   ```sh
   pip install -r requirements.txt
   ```
4. **Run the Jupyter Notebook**
   ```sh
   jupyter notebook
   ```
5. **Execute the Training & Prediction Scripts**
-  Train the model using notebooks/training.ipynb.
-  Test the model with main.py.
   

## 🎯 Usage
1. **Prepare Data: Place MRI images in the data/ directory.**
2. **Train the Model: Run the training.ipynb notebook to train the CNN model.**
3. **Test on New Data: Use main.py to classify new MRI images.**
4. **View Results: Accuracy, confusion matrix, and classified images are displayed.**
